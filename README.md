# Jumping Shrine Maiden

A 2D platformer inspired by Touhou Project by ZUN, built in GDevelop with Luis Leon.

Play it: link coming once the site is live

## Features
- Responsive movement
- Timed levels
- Platform mechanics: bounce, moving, and hit-activated platforms

## How it's built
Made in GDevelop using event-based programming. Exported to HTML5 so it runs in the browser.

## Roles
- Jinwang Li: wrote all the game logic (event-based programming), designed a couple of levels, set up all the resources in the engine, and playtested and debugged throughout development
- Luis Leon: provided the game resources and designed a couple of levels
